# awesome-seedance

Seedance 2.x 提示词 / Skills / 热门案例的中文浏览台。

来源：[aiwarts 开源长文](https://x.com/aiwarts/status/2102240456092626951) · 上游 [LearnPrompt/awesome-seedance](https://github.com/LearnPrompt/awesome-seedance)

## 跑起来

```bash
cd apps/awesome-seedance
bun install
bun run dev
```

打开 http://127.0.0.1:5177/

## MVP

- **模板**：27 条分类模板，按 6 大类筛选，一键复制「直接复制」引导语
- **Skills**：精选 16 条，一键复制 `npx` 安装命令
- **热门案例**：Top 12（按热度），海报 + 可复制 prompt；有公开复测 MP4 的可在详情播放

不接即梦 / Seedance API，不装 Agent Skill 到本机。
